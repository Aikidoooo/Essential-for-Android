# 期間限定アプリデザインの配布

## 発行する

このPCで `Essential-デザイン発行者/デザインQRを発行.cmd` を開き、デザインと開始・終了日時を入力します。PNG、署名済み文字列、発行記録JSONは `Essential-デザイン発行者/配布QR` に保存します。日時の `yyyy-MM-dd HH:mm` は日本時間です。ISO形式の日時には `Z` または `+09:00` 等のオフセットを付けられます。開始より終了が後、終了は未来、期間は最大366日です。

コマンド例：

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File scripts/New-DesignQr.ps1 -DesignId mint -StartsAt "2026-10-20 00:00" -EndsAt "2026-10-27 00:00"
```

デザインIDは default_light / default_dark / mint / sunset / violet / forest / ocean / ruby / sky / rose / reference です。アプリに登録済みのデザインを期間限定で開放します。

## アプリで受け取る

スキャナーのQRモードで読み取り、表示されるデザインと期間を確認して「デザインを受け取る」を押します。プロフィール → 設定 → **アプリデザイン** から選択します。開始前は選べず、期間内はレベル未達でも利用できます。既存のレベル解放はそのままです。

期間限定の利用権だけで選んでいたデザインは期限切れで直前の通常デザインへ戻します。レベル報酬で永久に解放済みのデザインには期間制限を付けません。同じQRを再読込しても期間は延長しません。

## 発行鍵と制約

デザイン専用RSA-3072／SHA256withRSA署名を使います。XP配布とは鍵と署名領域を分離しています。秘密鍵は `Essential-デザイン発行者/秘密鍵/design-issuer.dpapi` に、このWindowsユーザーのDPAPIで保護して保存しています。アプリには `app/src/main/assets/design-issuer-public.txt` の公開鍵だけを同梱し、発行機能と秘密鍵は同梱しません。発行者フォルダー全体はGit対象外です。鍵の再初期化による上書きは拒否します。公開鍵を変更すると旧鍵の配布QRは使えなくなります。

認証は正規の発行署名に対して行います。署名のない文字列や、デザイン・日時を改ざんしたQRは受け付けません。受取IDは各端末で一度だけ記録します。**コピーした正規QRを別端末で受け取ることは可能です。サーバーによる全端末一回限りの配布ではありません。**

期限の判定は端末時刻を使い、最後に確認した時刻を保存して、確認済みの期限切れが時刻の巻き戻しで復活しないようにします。端末時刻が不正確な場合は受取・利用が制限されることがあります。オフラインの仕組みなので、端末改造、データ削除・再インストール、バックアップの巻き戻し、発行PCの侵害まで完全に防止する保証はありません。秘密鍵は共有しないでください。

前面では期間の境界、起動／復帰／時刻変更／端末再起動では再確認します。ランチャーも期限切れ時に通常アイコンへ戻しますが、背景のアラーム配送とランチャーの表示更新はOSの省電力・キャッシュにより遅れる場合があります。アプリを開いた場合は期限を再検査します。
