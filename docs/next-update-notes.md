# 次回アップデートの紹介文案

・アプリアイコンのテーマに合わせて背景をアレンジしました。色のグラデーションに、各テーマの特徴を表した細やかな線画を重ね、ライト・ダーク両方で見やすくしました。
・ホーム上部の靄を取り除き、背景画像を鮮明に表示するようにしました。
・各テーマの背景はライト・ダーク両モードに対応します。アイコンの選択と表示モードを個別に変更できます。
・設定・アップデート画面のライト背景を、淡いラベンダー・ピンク・水色のグラデーションへ整えました。
・ホーム・機能一覧の端の伸縮演出と、設定タブの指に追従する滑らかな切り替えを追加しました。
・背景全体にテーマ色のグラデーションを広げ、濃淡がゆっくり流れるようにしました。

## 公開時の編集方針

背景変更は上記のように紹介し、着想元の作品名・登場人物名・関連設定には触れないこと。次回の版番号が決まったら、対応するリリースノートへこの紹介文を統合する。




・次回更新（versionCode 30以降へ初めて更新）後の初回起動から7日間、全アプリデザインを期間限定で解放します。再起動・後続更新で期間は延長されません。レベルで解放済みのデザインは終了後も利用できます。期間限定のデザインを選択していた場合は、直前の通常デザインへ戻ります。新規インストールは対象外です。
